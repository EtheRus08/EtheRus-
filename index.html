玩法引导

账号与登录

输入昵称 + 密码即可登录，首次输入自动注册

登录后成绩进入在线排行榜，噩梦难度解锁进度按账号保存

不登录也能玩，数据仅保存在本机

基础操作

音符从上方落下，到达底部白线时按下对应按键

DFJK

游戏中按 Esc 暂停

判定与音符

PERFECT　精准命中，300 分档

GOOD　稍有偏差，100 分档

BAD　偏差较大，不断连

MISS　未击中，连击清零

长条音符需要按住到尾部圆点再松开；两个轨道同时出音符就是双押

难度与评级

每关四个难度：简单 / 普通 / 困难 / 噩梦

结算评级 F → C → B → A → S（全完美）

在某关的困难难度拿到 A 以上，解锁该关的噩梦难度

还可以换主题、导入自己的音乐游玩
